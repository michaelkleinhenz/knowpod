# shine

Fixed-point MP3 (MPEG-1/2 Layer III) encoder used to compress recordings on
boards built with `REC_MP3`. These are the unmodified library sources from
<https://github.com/toots/shine> (`src/lib`, commit ab5e352); the command-line
tool and build files are left out. Licensed under the GNU LGPL 2.0, see COPYING.

Public API: `layer3.h` (include it inside `extern "C"`).
